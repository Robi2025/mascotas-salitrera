# Mascotas Salitrera Maria Elena

App interna para residentes del condominio Salitrera Maria Elena, enfocada en registrar mascotas.

## Objetivo
Registrar mascotas con:
- Nombre
- Tipo (perro/gato)
- Departamento
- Contacto del dueno

## Estructura
- `backend/` API REST simple (Node.js + Express) con SQLite.
- `frontend/` interfaz web estatica para registrar y listar mascotas.

## Proximos pasos sugeridos
1. Instalar dependencias en `backend/`.
2. Configurar variables en `.env`.
3. Levantar la API y abrir el frontend.
